# Publier le projet sur votre compte GitHub

Compte prévu : **BouchamiMohamed**. Dépôt proposé : **course-companion-nlp**.

1. Décompressez `Projet_NLP_Pret_pour_GitHub.zip` dans un dossier accessible.
2. Connectez-vous à votre compte, puis ouvrez https://github.com/new.
3. Vérifiez le propriétaire **BouchamiMohamed** et nommez le dépôt **course-companion-nlp**.
4. Choisissez la visibilité. Pour un dépôt privé, donnez accès au professeur. Pour un dépôt public, vérifiez les droits sur les extraits de cours présents dans le rapport et les résultats.
5. Ne cochez pas l'ajout d'un README, d'une licence ou d'un fichier .gitignore : le paquet contient déjà le README et le .gitignore. Cliquez sur **Create repository**.
6. Sur la page du dépôt vide, cliquez sur **uploading an existing file**. Si le dépôt contient déjà des fichiers, choisissez **Add file > Upload files**.
7. Glissez les fichiers et sous-dossiers extraits du paquet dans la zone de téléversement. Envoyez leur contenu, pas le ZIP lui-même. Vérifiez que `app.py`, `README.md`, `study_assistant/`, `rapport/` et `tests/` se trouvent à la racine du dépôt.
8. Saisissez le message `Ajout du projet NLP - assistant pédagogique`, puis cliquez sur **Commit changes**.
9. Le lien du dépôt sera https://github.com/BouchamiMohamed/course-companion-nlp si vous avez choisi ce nom. Copiez l'adresse du navigateur et testez l'accès accordé au professeur.
10. Vérifiez le rapport PDF dans `rapport/`. Actualisez son état de publication et réalisez l'évaluation humaine demandée avant la remise finale.

Ne téléversez pas le dossier original complet du Bureau : `.venv/`, les poids de modèles et les PDF de cours ne sont pas nécessaires. Le paquet préparé les exclut.
GitHub publie ici le code ; il ne fait pas fonctionner automatiquement le serveur Streamlit/Ollama.

Documentation officielle : https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository
